## Tier 3 — Derived (computed from Tier 1)

### Implied rate: ₹7,700 per sq.ft., inclusive of taxes

The brief never states a per-sq.ft. rate. It is recoverable from the price band, and both ends agree:

```
₹92,40,000  ÷  1,200 sq.ft.   =  ₹7,700 / sq.ft.
₹7,700      ×  3,199 sq.ft.   =  ₹2,46,32,300   ≈  ₹2.46 Cr   ✓
```

Every HNI and NRI investor asks for the per-sq.ft. rate within the first ninety seconds.
This lets the agent answer instantly, and — critically — **consistently with every other number
it quotes**, because it is derived from those same numbers rather than fetched from a listing.

## Tier 4 — Explicitly BLOCKED (do not state under any circumstance)

Public property aggregators are scraped, stale, and frequently wrong. Encountered and rejected:

| Blocked claim | Source problem |
|---|---|
| ₹8,300/sq.ft. base rate | Contradicts the brief's implied ₹7,700 inclusive rate |
| Plot sizes up to 4,000 sq.ft. | Brief caps at 3,199 sq.ft. |
| Top price ₹3.08 Cr | Brief caps at ₹2.46 Cr |
| "₹39.6 lakh for 1,200 sq.ft." | Wildly stale — off by more than half |
| "₹33,000/sq.ft." | Scraping artifact, physically implausible |
| "Ready to Move" status | Flatly false — possession is December 2029 |
| Interior specs (vitrified tiles, granite platforms, split-AC provision) | **This is a plotted development. There are no interiors.** Aggregator template pollution. |

The last row is the most dangerous: an agent that describes flooring in a **land sale** destroys
its credibility in one sentence and exposes the developer on a RERA-registered project.

## Unknowns — deflect to the Property Expert

The agent must never improvise on any of these. Each has a scripted deflection.

- Exact price of a specific plot number
- Payment schedule, construction-linked plan, booking amount
- Home-loan tie-ups, approved banks, EMI figures
- Registration/stamp duty/khata specifics
- Plot availability, current phase inventory, which plots remain
- Discounts, negotiation, launch offers
- Site visit logistics and transport
- NRI-specific: repatriation, FEMA/RBI treatment, NRE/NRO payment routes, PoA
- Rental yield or appreciation *percentages* (directional language only — never a number)
- Anything about competing projects

**Standard deflection:**
> "That's exactly the kind of detail our Property Expert can confirm precisely — I don't want to
> give you a number that isn't exact. Shall I have them cover it on the call?"

This doubles as a CTA. A limitation, converted into a close.

## Legal / compliance notes

- **RERA-registered project.** Misquoting price, area, or possession is a compliance exposure for
  the developer, not merely an error. This is the reason for the Tier-4 block list and the
  hard no-invention rule.
- **Possession December 2029** must never be softened, rounded, or implied to be sooner.
- **"Inclusive of taxes"** is part of the price claim and travels with it.
- **Consent-first.** The agent asks permission before proceeding and honours any refusal or
  do-not-call request immediately and without a rebuttal attempt.
